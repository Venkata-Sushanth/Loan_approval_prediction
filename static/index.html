How LoanWise Works
A complete walkthrough of the data science pipeline behind your loan predictions.
📂
The Dataset

Source: Loan Prediction Dataset — Banking (Kaggle)
Size: 381 applicants with 12 features each
Target: Loan_Status — Approved (Y) or Rejected (N)
Class balance: 71.1% approved, 28.9% rejected

Loan_ID Gender Married Dependents Education Self_Employed ApplicantIncome CoapplicantIncome LoanAmount Loan_Amount_Term Credit_History Property_Area
⚗️
Engineered Features (Created from Original Data)

5 new features were computed from the raw columns to help models detect patterns individual columns can't capture:

Total_Income Log_Total_Income EMI Debt_Income_Ratio Income_Per_Dependent Loan_Income_Ratio
🔧
Full ML Pipeline — Step by Step
1

Load & Inspect Data

Read loan_data.csv with 381 rows and 13 columns. Check class balance, column types, and missing value counts.

2

Data Cleaning

Remove Loan_ID (not a predictor). Convert Dependents '3+' → 3 (numeric). Fill missing values in Credit_History, Loan_Amount_Term, Gender, Self_Employed using mode (most common value). Total missing filled: 75 values across 5 columns.

3

Feature Engineering

Create 6 new features: Total_Income (combined earnings), Log_Total_Income (reduces income skew), EMI (monthly repayment estimate), Debt_Income_Ratio (repayment burden), Income_Per_Dependent (financial stress), Loan_Income_Ratio (loan burden).

4

Preprocessing Pipeline

Numerical columns: SimpleImputer (median) → RobustScaler (scale using median+IQR, resistant to income outliers).
Categorical columns: SimpleImputer (mode) → OneHotEncoder (convert Gender, Married etc. to 0/1 flags).

5

Train/Test Split

80% training (304 samples), 20% test (77 samples). Stratified split — approval rate is preserved equally in both sets.

6

4 Models Trained

⚡ Gradient Boosting: 200 sequential trees, each corrects previous errors.
🌲 Random Forest: 200 independent trees with balanced class weights, voting together.
📈 Logistic Regression: Linear separator with regularisation — most interpretable.
🔵 KNN Classifier: Finds 11 most similar past applicants and lets them vote.

7

5-Fold Cross Validation

Training data split into 5 parts. Each part tested once while model trains on remaining 4. Gives reliable AUC mean and std — showing how consistent the model is across different data subsets.

8

Feature Dependency Analysis

Each of 17 features removed one at a time. All 4 models retrained. AUC drop measured. Total: 68 model training experiments. Shows which features drive predictions and which add noise.
